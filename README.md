
# 🚀 DSA_IN_JAVA

A comprehensive collection of **Data Structures and Algorithms** implemented in Java. This repository is designed to track progress, document problem-solving patterns, and serve as a quick reference for technical interviews.

---

## 📂 Repository Structure

The project is organized by problem categories and algorithmic patterns to make navigation easy:

| Category | Description |
| --- | --- |
| **`ArrayProblems`** | Basic and advanced operations on 1D/2D arrays. |
| **`TwoPointerApproach`** | Optimized solutions for searching and sorting using two pointers. |
| **`windowproblem`** | Sliding window techniques for subarrays and substrings. |
| **`StringProblems`** | Manipulation, pattern matching, and character analysis. |
| **`GeneralProblems`** | Logic-based problems, math-oriented challenges, and miscellaneous. |

---

## 🛠️ Tech Stack & Tools

* **Language:** Java (JDK 8+)
* **IDE:** Eclipse (includes `.project` and `.classpath` configuration)
* **Version Control:** Git & GitHub

---

## 🚀 How to Use This Repo

### 1. Clone the repository

```bash
git clone https://github.com/lijoraj-p-r/DSA_IN_JAVA.git

```

### 2. Import into your IDE

* **Eclipse:** `File > Import > Existing Projects into Workspace`
* **IntelliJ/VS Code:** Simply open the root folder; it will detect the Java source files.

### 3. Run a specific problem

Navigate to `src/com/<category>/` and run the desired Java file:

```bash
java FileName.java

```
